## 产品概述

改版「收藏日历」页，按用户提供的参考截图重做视觉与信息结构：日期格的占位圆点标签升级为**当天袋子的缩略图直铺**，页面底部新增两张卡片（左：本月统计占位；右：文件夹样式的今日收藏袋子）。

## 核心功能

- 标题区改为「今天」大标题 + 完整日期副标题「2026年10月16日，周五」格式；选中/切月时标题联动（选中日 →「M月D日」，非当月 →「YYYY年M月」）。
- 星期头改为完整两字「周日 周一 … 周六」（周日为首日，保持不变）。
- 日期格三分支：
- 无收藏：浅米色圆角方块 + 数字（保留现状）。
- 有收藏：当天第一件袋子的缩略图铺满格子（圆角裁切、隐藏数字），当天多件时右上角橙色圆形「×N」角标。
- 今天：有收藏 → 白底 + 焦糖色描边环 + 缩略图；无收藏 → 焦糖实心 + 白字（保留）。
- 底部双卡（并排）：
- 左卡「本月」：本月收藏件数大数字 + 「N 家店铺」（按当月收藏去重 shelfName 计算；无数据显示占位文案），右侧点缀 1~2 张本月袋子缩略图。
- 右卡「文件夹」：纯 CSS 文件夹造型，今日加入的袋子缩略图（最多 3 张，轻微错位旋转）从文件夹上方探出；今日无收藏显示空文件夹。
- 月份切换「‹ ›」保留但样式弱化融入新视觉；移除原「点日期滑出当天明细列表」面板（信息由底部双卡承接）。
- 数据仍复用 `GET /collectibles`（缩略图 URL 列表接口已返回），无后端改动；首页入口不动。

## Tech Stack

- uni-app（Vue 3 + TypeScript）微信小程序，仅构建 mp-weixin，沿用现有页面写法。
- 仅修改 `apps/miniapp/src/pages/calendar/index.vue` 单文件（script + template + style），无后端、无路由、无首页改动。

## Implementation Approach

- 数据层不变：`dataService.collectibles('limit=1000' + cursor 翻页)` 聚合为 `Map<'YYYY-MM-DD', CollectibleSummary[]>`；`CollectibleSummary.thumbnailUrl`（后端签名 URL）直接用于格子与文件夹缩略图，零新增请求。
- 新增派生 computed：
- `monthStats`：遍历 grouped，统计 viewYear/viewMonth 当月件数与去重 shelfName 数（O(n)，n 为当月条目数）。
- `todayBags`：`grouped.get(todayKey)` 前 3 件（缩略图 + 旋转错位参数按索引取模）。
- `headTitle / headSubtitle`：按 selectedDate 与查看月份三分支输出。
- 单元格渲染三分支：`count>0` 渲染 image（aspectFit）+ ×N 角标；`isToday && count>0` 白底焦糖描边环；否则数字格。缩略图加载失败回退为数字格（@error 标记 failed map，沿用项目既有做法）。
- 性能：格子缩略图与列表接口同源、总量小（个人收藏量级），无虚拟化必要；不引入新依赖。

## Implementation Notes

- 月份切换按钮保留（参考图未画但功能必需），样式收敛为小圆形弱化按钮。
- 移除上一版当天明细列表面板与其样式，避免死代码；`selectedDate` 点击行为保留仅用于头部标题联动。
- 空态/加载沿用现有 skeleton（35 格）与 `cal-error` 样式。
- 验证：`pnpm --filter @bagcollect/miniapp typecheck` 与 `build:mp-weixin:local` 构建通过，dist 产物包含日历页。
