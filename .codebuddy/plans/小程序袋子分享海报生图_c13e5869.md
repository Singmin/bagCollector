## 产品概述

在「袋子详情」弹层的右上角新增一个分享按钮。用户点击后，小程序用官方卡牌模板图 + 袋子图片 + 文案在本地生成一张分享海报，生成完成后直接调起微信「发送给朋友」的图片分享面板，把海报作为图片发送出去。

## 核心功能

- 右上角分享按钮：与现有「心愿 / 标记已有」按钮并排展示，心愿袋与自己的收藏均可分享。
- 海报生成：以「官方卡牌1-1.png」为背景，袋子图片等比居中放入模板上半部黄框内。
- 海报文案：中间展示袋子名称、收藏架/品牌（心愿袋显示「官方精选」）、收藏日期与入库时长。
- 底部水印：保留「@袋袋集 · 2026」金色居中水印。
- 分享调起：生成期间显示加载提示，生成成功后直接调起微信「发送给朋友」图片分享面板（wx.showShareImageMenu）。

## 技术栈

- 框架：uni-app（Vue 3 + TypeScript），目标平台为微信小程序。
- 海报绘制：微信离屏 Canvas 2d（`wx.createOffscreenCanvas({ type: '2d' })`），绘制后通过 `wx.canvasToTempFilePath` 导出临时图片路径。
- 分享能力：`wx.showShareImageMenu({ path })` 直接调起「发送给朋友」图片面板。
- 图片下载/尺寸获取：复用现有 `uni.getImageInfo` 模式（`services/use-library-collection.ts`、`services/images.ts` 已有同款用法）。

## 实现方案

### 整体思路

新增一个纯函数式海报生成服务，内部完成「加载模板本地图 → 获取袋子图 → 离屏 canvas 按坐标绘制 → 导出临时文件」，页面组件只负责触发、展示 loading 与调起分享面板。这样海报生成逻辑与 UI 组件解耦，便于后续复用或替换模板。

### 关键技术决策

- **用离屏 canvas 而非页面内 canvas**：项目 `package-editor/pages/crop/index.vue` 曾记录 iOS 真机页面内 canvas 2d 首次绘制崩溃（`a.isMagicBrushCanvas`），离屏 canvas 走不同渲染链路，可规避该崩溃面，且不占用页面渲染节点。
- **袋子图统一等比缩放（aspectFit）居中放入黄框**：避免裁切/拉伸变形；优先使用 `displayImageUrl`（正面标准图），若存在 `cutoutImageUrl`（透明抠图）则优先使用透明图以获得更贴合卡牌的观感。
- **远程图通过 `uni.getImageInfo` 先转为本地缓存路径再绘制**：`img.newdawntech.cn` 已在小程序 downloadFile 白名单内，getImageInfo 会完成下载并返回可用路径，同时顺带拿到宽高用于 aspectFit 计算。
- **文案字段**：袋子名称 + 收藏架/品牌 + 收藏日期 + 入库时长。日期/时长复用 `services/format.ts` 的 `formattedDate(value, '-')` 与 `daysAgoText(value)`，与详情页口径完全一致。
- **分享失败兜底**：`wx.showShareImageMenu` 对基础库版本有要求，调用前做能力检测；生成或调起失败统一 `uni.showToast` 提示，不打断详情页。

### 性能与可靠性

- 生成链路为一次性短任务：1 次模板本地图 + 1 次袋子图 getImageInfo + 1 次 canvas 绘制，耗时可控；生成期间用 loading toast 反馈，避免重复点击（生成中加 busy 标记）。
- 海报画布尺寸取模板 2 倍（约 636×1024），保证发送到聊天后仍清晰；本地模板 255KB 打进主包，需确认增量后主包仍低于 2MB（模板仅一张，风险低）。
- 所有临时文件由微信管理，无需手动清理。

## 实现要点

- **模板坐标**：黄框内卡片区实现阶段需量取模板像素后微调；预估约 x∈[9%,91%]、y∈[12%,59%]（以 318×512 为基准）。文案区在黄框下方，底部水印居中对齐、颜色参考详情卡背面 `#a48000`。
- **字体**：名称使用衬线 `Georgia, "Songti SC", serif`，其余文案使用系统无衬线，与详情卡视觉一致。
- **按钮交互**：分享按钮放入 `.detail-quick` 组，沿用 `.detail-quick__btn` / `.detail-quick__icon` 样式；点击后 `detailBusy` 不拦截分享（分享是独立弹层动作），但需防止生成中的重复点击。
- **loading 文案**：`正在生成分享图…`；失败提示可读错误信息，避免大段堆栈。
