## 一、收藏详情分享海报生图

在袋子详情弹层右上角新增「分享」按钮：点击后用官方卡牌模板图 + 袋子图 + 文案在离屏 canvas 生成一张分享海报，生成后直接调起微信「发送给朋友」图片分享面板（`wx.showShareImageMenu`）。

### 改动

1. **分享入口** `apps/miniapp/src/components/LibraryDetailOverlay.vue`：右上角 `.detail-quick` 按钮组新增分享按钮（心愿袋与自己的收藏都显示）；点击走 `shareBag()`：loading「正在生成分享图…」→ 生成海报 → 调起发送面板，失败 toast 提示。
2. **海报生成服务** `apps/miniapp/src/services/share-poster.ts`（新增）：
   - 用 `wx.createOffscreenCanvas({ type: '2d' })` 绘制，规避 crop 页记录过的 iOS 屏内 canvas 崩溃面；
   - 海报画布取模板 2 倍（636×1024）保证清晰；`wx.canvasToTempFilePath` 导出临时图；
   - 文案：袋子名称 + 收藏架/品牌 + 收藏日期 + 入库时长（复用 `services/format.ts`，与详情卡口径一致）；心愿袋品牌标注「官方精选」，日期/时长标签改用「上架日期 / 上架天数」；底部水印 `@袋袋集 · 2026`；
   - 袋子图优先级：透明抠图 `cutoutImageUrl` → 正面高清图 → 首图 → 缩略图。
3. **静态资源**：新增模板图 `apps/miniapp/src/static/share/share-card-1-1.png`（官方卡牌，318×512）、分享图标 `apps/miniapp/src/static/figma/share.svg`。

### 关键技术点

- 模板图是**代码包内静态资源**，必须用 canvas 的 `createImage()` 直接加载包内路径；不能走 `uni.getImageInfo` —— 它会把 `/static/...` 误判为网络 URL 请求（报 500）。袋子图是远程 CDN 图，仍用 `getImageInfo` 下载并取宽高。
- `wx.createOffscreenCanvas` / `wx.showShareImageMenu` 为微信专属 API，`uni-app` 类型未收录，服务内直接访问运行时 `wx` 全局。
