# 改动记录（2026-10-18）

分支：`feature/white-stroke-toggle`
范围：白边开关（用户可切换有白边 / 无白边）

---

## 一、背景

10-17 上线了白描边（贴纸效果），所有抠图/透明图都被加上了白边。有用户反馈白边不好看，
于是做成**用户可切换**：设置页一个开关，开 = 有白边，关 = 无白边。开关存服务端（换设备一致）。

核心结论：无白边的源图（`CUTOUT` 透明抠图、`STANDARD`）一直保留在数据库和 COS 里，
白边只在最后一层 `DISPLAY`/`THUMBNAIL` 上画上去，所以随时能补无白边版。

## 二、产品行为

- 开关默认**关**（默认不显示白边）。
- 开 = 显示有白边版；关 = 显示无白边版。
- 生效范围：官方袋子 + 用户收藏（收藏架、展架、图鉴、日历、首页所有展示场景）。
- **只有「实际加了白边」的透明口径才有两套图**：抠过图的照片、保留透明度的 PNG；
  白底实拍照片（只裁剪没抠图）本来就不加白边，只有一套，开关切了图也不变。

## 三、改动明细

### 数据库

1. `apps/api/prisma/schema.prisma`：
   - `AssetKind` 枚举新增 `DISPLAY_PLAIN`、`THUMBNAIL_PLAIN`（无白边版展示图/缩略图）。
   - `User` 新增 `whiteStrokeEnabled Boolean @default(false)`（白边开关，默认关）。
2. 迁移 `apps/api/prisma/migrations/20261018010000_white_stroke_toggle/migration.sql`：
   `ALTER TYPE "AssetKind" ADD VALUE`（两个新枚举值）+ `ALTER TABLE "User" ADD COLUMN`。

### worker 出图

3. `apps/worker/src/processor.ts`：`writeRenditions()` 在「实际加了白边」时，用同一张 trim 后未描边的
   素材再派生 `DISPLAY_PLAIN`/`THUMBNAIL_PLAIN` 写 COS + 落库；无白边版写库失败（如存储配额不足）
   **降级处理**，不让整张图失败。
4. `apps/worker/src/official-processor.ts`：`writeOfficialRenditions()` 同样派生无白边版。

### 契约 / API

5. `packages/contracts/src/image-sides.ts`：`ImageSideDto` 加 `thumbnailUrlPlain`、`displayImageUrlPlain`。
6. `packages/contracts/src/index.ts`：`CollectibleSummaryDto`/`CollectibleDto`/`OfficialBagDto` 加 `*Plain` 字段；
   新增 `updateAccountSchema`。
7. `apps/api/src/common/image-sides.ts`：`imageData()` 映射 `THUMBNAIL_PLAIN`/`DISPLAY_PLAIN` 到无白边字段。
8. `apps/api/src/collectibles/collectibles.service.ts`：列表 `toSummary`/详情 `toDto` 返回无白边字段；
   `listInclude` 纳入 `THUMBNAIL_PLAIN`。
9. `apps/api/src/feed/feed.service.ts`：`imageUrls()` 纳入 plain kind；`toFeedItem()` 返回无白边字段。
10. `apps/api/src/official-bags/official-bags.service.ts`：`toDto()` 返回无白边字段。
11. `apps/api/src/auth/auth.controller.ts` + `auth.service.ts`：`GET /account` 返回 `whiteStrokeEnabled`；
    新增 `PUT /account` 更新偏好。
12. `apps/api/src/submissions/submissions-admin.service.ts`：`promote`（用户袋子纳入官方库）复制图片时
    一并复制 `CUTOUT`/`DISPLAY_PLAIN`/`THUMBNAIL_PLAIN`。

### 小程序

## 部署命令清单

> 服务器：`111.230.17.245:6222`（root，密钥 `~/.ssh/bagcollect_deploy`）。
> 部署目录 `/www/wwwroot/bagcollect`，容器 `infra-api-1` / `infra-worker-1` / `infra-postgres-1`。
> CI secrets 在 GitHub production environment，推 main 自动触发。

### 第 1 步：推代码触发部署（自动迁移）

```bash
git push origin feature/white-stroke-toggle
# 或合并到 main 后 push。CI 会：构建镜像 → rsync 传输 → docker load → 起库 → 自动跑 prisma migrate deploy → 切容器。
```

迁移是**自动**的（`deploy.sh` 里 `compose up --no-deps --exit-code-from migrate migrate`），
新迁移会给 `AssetKind` 加两个枚举值、给 `User` 加 `whiteStrokeEnabled` 列，无需手动跑。

### 第 2 步：确认部署成功

```bash
ssh -i ~/.ssh/bagcollect_deploy -p 6222 root@111.230.17.245 \
  "cd /www/wwwroot/bagcollect && docker compose --env-file infra/.env.deploy -f infra/docker-compose.yml ps"
```

### 第 3 步：回填无白边版（必须先跑，否则默认关的状态下旧图无 plain 可显示）

先 dry-run 统计数量：

```bash
ssh -i ~/.ssh/bagcollect_deploy -p 6222 root@111.230.17.245 \
  "docker cp /www/wwwroot/bagcollect/scripts/backfill-stroke-plain.mjs infra-worker-1:/app/backfill-stroke-plain.mjs && \
   docker exec infra-worker-1 node /app/backfill-stroke-plain.mjs"
```

> 若 `/www/wwwroot/bagcollect/scripts/` 不在服务器上（脚本只随 git 存在本机），先单独 scp 脚本：
> ```bash
> scp -i ~/.ssh/bagcollect_deploy -P 6222 scripts/backfill-stroke-plain.mjs \
>   root@111.230.17.245:/www/wwwroot/bagcollect/scripts/backfill-stroke-plain.mjs
> ```

确认数量无误后正式执行：

```bash
ssh -i ~/.ssh/bagcollect_deploy -p 6222 root@111.230.17.245 \
  "docker exec infra-worker-1 node /app/backfill-stroke-plain.mjs --execute"
```

脚本会输出 `refreshUrlCount` 和 URL 清单路径（默认 `/tmp/stroke-plain-backfill-urls.txt`）。

### 第 4 步：刷新 CDN

回填是**新增**无白边对象（新 key），CDN 首次访问会回源，通常无需刷新；
但为保险，把回填脚本输出的 URL 清单在腾讯云控制台「CDN → 刷新预热」提交 URL 刷新。

> 之前 10-17 的 `backfill-stroke.mjs` 是**覆盖写**旧 key，必须刷 CDN；
> 本次 `backfill-stroke-plain.mjs` 是**新增** key，理论上不刷也会回源，刷了更稳。

### 第 5 步：验证

```bash
# 确认无白边资产已落库（数量应约等于抠图/透明口径的资产数）
ssh -i ~/.ssh/bagcollect_deploy -p 6222 root@111.230.17.245 \
  "docker exec infra-postgres-1 psql -U bagcollect -d bagcollect -tAc \
   \"SELECT kind, count(*) FROM \\\"OfficialBagImage\\\" WHERE kind IN ('DISPLAY_PLAIN','THUMBNAIL_PLAIN') GROUP BY kind\""
```

小程序端：设置 → 抠图白边开关，切换后收藏架/图鉴应显示无白边（默认关）。
