# UI 改动记录 · 第二轮（2026-09-27）

接续 `docs/UI-CHANGES-2026-09-26.md`（第一轮，提交 1220023）。本轮集中在首页挂袋区、底部导航栏、编辑半窗交互与全部收藏页搜索行的多轮微调。

> 分支：`feature/ui-revamp`（续）

---

## 一、底部导航栏

- **高度**：176 → **150rpx**；页面底部留白（212→186rpx）与防穿透护垫同步收窄
- **＋胶囊调矮**：96 → 80 → **68rpx**（两轮），圆角同步 34rpx，始终与两侧条目垂直同轴（bottom 补偿）
- **新增 `hidden` 态（关键修复）**：编辑半窗拉起时整条底栏下滑隐藏（`translateY(110%)`，0.32s），关闭时还原
  - 背景：自定义 tabBar 是框架层渲染、永远盖在页面内容之上，页面 z-index 压不住；蒙一层仍会露轮廓，只能让它自己让位
  - 涉及 `services/tab-bar.ts`（新增 `setTabBarHidden`）、`custom-tab-bar/{js,wxml,wxss}`、页面接线（startEdit / cancelEdit / saveEdit / closeDetail 四处）

## 二、编辑半窗交互（全部收藏页）

- **点「编辑」→ 详情卡关闭 + 半窗拉起**（此前是半窗盖在卡片上）；详情卡 `v-show="!editing"`，`detailItem` 数据保留供保存写回
- **保存成功 / 取消 / 点遮罩** → 半窗与卡片一并关闭，回到列表（`applyUpdated` 已先把改动铺进列表，关闭顺序安全）
- **只读条（编号 / 收藏日期 / 入库时长）**：三块改为 `flex: 1 1 0` 严格等宽，文案在各自格内水平居中（原先是内容定宽 + 时长右对齐）

## 三、全部收藏页 · 搜索行

- **搜索框材质复制自宫格按钮**：白色半透明描边 + 半透明白底（原深灰描边）；随后按要求去掉了外投影（保留顶沿内高光）
- **宫格 / 展架切换钮**：
  - 字重 650 → 400（与搜索框文字一致）
  - 字号 24rpx（12px）→ **20rpx（10px）**
  - 图标与文字间距 10 → 6 → **8rpx（最终 4px）**
  - 上下内边距对称（14rpx）+ `justify-content: center`，内容在按钮内垂直居中（等高拉伸下也保持）
  - 去掉外投影（与搜索框一致）
  - 文字 `letter-spacing` 尾随空隙用负 margin 抵消，图标与文字严格同轴
- **展架 icon（shelf.svg）**：三条横杠中轴对齐（原楼梯状错位）并加长（12→16 宽）；与宫格 icon 大小/颜色/描边 1:1（`#333333`、视框归一）
- **搜索 icon（search.svg）**：尺寸 44→36→最终 **32rpx（16px）**；视框裁到 `2.5 2.5 20 20` 修复左边被裁与垂直居中；描边 1.8→2

## 四、首页

### 1. 大卡片
- 高度 636 → **612rpx**（再矮 12px）
- 右上角黄色光斑修复：`indexBg.svg` 光带朝右上平移 18px 并加宽，模糊滤镜区域扩大——光晕现在顶满卡片上边与右边（原光带实体边缘离角 31px，模糊衰减后够不到边）

### 2. 挂袋区
- **卡片缩小（方案 A）**：卡宽 175 → **160rpx（80px）**，重叠 22 → 20rpx，一屏可见约 5 张；meta 字号按卡宽等比缩
- **卡片边框统一**：边框改不透明白 `#ffffff`、玻璃底提高不透明度（58%~80%）、移除 `backdrop-filter` —— 消除各卡片之间的细微色差与真机渲染差异（选中红环保留）
- **滑轮 / 挂杆对齐（关键修复）**：`--rail-center` 调整到低于滑轮半径（19.5+2rpx）时轮顶会被 scroll-view 裁掉；曾用 padding 补偿导致轮心与杆心错位 8rpx，最终方案 `--rail-center: 26rpx`（轮顶留 4.5rpx 余量），轮心 = 杆心严格同轴
- **副行与挂袋区间距**：22 → 8 → 12 → 32 → 最终 **18rpx**
- **提示文案**「↤ 左右滑动 · 轻点在上方查看 ↦」：字号/颜色/字距与大卡片「轻点翻面 · 查看详情」完全一致（`#c0bab1` / 20rpx / 0.5rpx，去掉 opacity 叠加），顶部间距 15 → 2rpx 上移

### 3. 背面
- 删除「查看完整详情 →」入口（按钮 + `openHero()` + 样式），并**整体删除 `package-library` 分包**（`pages.json` 注册 + `pages/detail/index.vue`，全工程唯一入口已确认为此）
