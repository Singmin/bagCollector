# UI 改动记录 · 2026-10-02（图像编辑器 & 首页/收藏交互）

> 分支 `feature/editor-polish`。服务端改动见 `docs/CHANGES-2026-10-02*.md`，本文只整理 UI。

## 一、完善信息页（metadata）——三个入口按钮

| 项 | 改动 |
|---|---|
| 布局 | 三入口由纵向整行堆叠改为**一行三等分**（flex: 1 1 0，gap 14rpx） |
| 图标 | 三个统一为同一套线性描边规格（24 viewBox / stroke-width 2 / 圆角端点），32rpx 呈现；样式、视觉大小、笔画粗细完全一致 |
| 文案 | 统一四字：**裁剪旋转 / 高级调色 / 自动抠图** |
| 自动抠图 | 常驻展示；已抠图时变**完成态**（灰字 `#b3afa8` + 淡边框 + 图标压暗 45%），禁用不可点；写在 `[disabled]` 之后覆盖微信默认的半透明 |
| 间距 | 按钮行与下方表单间距 6rpx → **32rpx** |
| 边框 | 调色入口的虚线边框移除，三钮统一实线 |

## 二、裁剪旋转页（crop）——大改版

| 项 | 改动 |
|---|---|
| 画布 | 去黑色背景 → **纸感白底圆角卡**（`#fffdf8` + 1rpx 细边框 + 柔影，圆角 32rpx，canvas 本体 30rpx）；高度 56vh（460~800rpx）随屏伸缩 |
| 工具行 | 「图标在上 · 文字在下」无胶囊底工具行，**比例（3:4 / 2:3 / 原图）与旋转（旋转 90° / 重置）同排一行等宽**；选中项文字变品牌红 `#C50405` |
| 调色 | 亮度 / 对比度 / 饱和度滑杆**常驻**（裁剪与调色共用一页） |
| 滑杆 | 统一「标签 / 滑杆 / 数值」三列，轨道色 `rgba(20,20,20,.13)`，block-size 20，去原生 show-value 气泡 |
| 底部确认 | 大胶囊按钮 → **✕ / ✓ 圆形轻量钮**（88rpx，右钮黑底白勾），忙态变淡 |
| 模式合并 | 删除 `mode=color`「仅调色」独立模式，与裁剪旋转**完全复用同一页面**（该模式原为画布铺满、只有调色杆） |
| 新增图标 | ratio-34 / ratio-23 / ratio-free / rotate-cw / rotate-ccw（24 viewBox 线性描边，与全站图标同风格） |

## 三、拍照上传页（add）——流程与反馈

| 项 | 改动 |
|---|---|
| 状态页 | 去掉独立「处理中」状态页；上传完成后**本页状态行反馈**，完成直接跳完善信息页 |
| 状态行文案 | `正在压缩照片 → 正在上传 N% → 正在处理图片`（修正过时的「正在启动自动抠图」） |
| 等待反馈 | 不弹 loading 蒙层，仅状态行；失败/超时（30s）回到拍照页并可重拍 |
| 压缩 | 上传前长边压到 **2048px**（展示图产出上限）+ 质量 80 —— 上传与处理时间约为原来的 1/3 |

## 四、陈列页（showcase / 首页）

| 项 | 改动 |
|---|---|
| 卡片背面 | 内容超高时**卡内上下滚动**（scroll-view + enhanced + show-scrollbar=false，不显示滚动条） |
| 靶心图标 | 按「标记已有」状态切换：未标记黑色 `target.svg` / 已标记品牌红 `target-marked.svg`；撤回后复原 |
| 背面按钮 | 「标记已有 / 已拥有」双态同步（点击语义一致：已拥有 → 弹删除确认） |
| 精选上新 | 展示数量不限（一次取全，后端上限放宽至 1000）；挂袋区**虚拟列表渲染**（同事 c700e44）；滑到底自动追加兜底 |
| 下拉刷新 | 修复下拉拽动顶部标题栏（移除页面级 `enablePullDownRefresh`，补 `disableScroll`） |
