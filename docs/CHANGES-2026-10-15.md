# 改动记录（2026-10-15）

分支：`feat/back-side-and-admin-improvements`
范围：收藏/袋子 B 面（反面）图展示、后台列表服务端排序、扫样纠正预览、匹配结果按钮

## 一、收藏 / 袋子 B 面（反面）图展示

给「收藏摘要」补上 B 面缩略图字段，让小程序详情卡和发现页主展位在打开瞬间就能判断是否存在反面图，直接按 A/B 布局渲染，不必等详情接口返回后再跳变。

### 改动

1. **契约** `packages/contracts/src/index.ts`、**类型** `apps/miniapp/src/types.ts`：`CollectibleSummaryDto` / `CollectibleSummary` 新增 `backThumbnailUrl?: string`（有值即表示存在已发布的 B 面图）。
2. **后端收藏摘要** `apps/api/src/collectibles/collectibles.service.ts`：`toSummaryDto()` 按详情同口径判断 B 面是否存在（`sourceVersion > 0` 或 `publishedVersion !== null`），有则返回 `backThumbnailUrl`；`CollectibleInclude` 里的缩略图查询由「只取 FRONT」改为「FRONT + BACK」。
3. **后端 feed** `apps/api/src/feed/feed.service.ts`：批量取图从「只取正面」改为「正反面都取」，`ImageUrlResolver` 增加 `side` 参数，feed 条目同样返回 `backThumbnailUrl`。
4. **详情卡** `apps/miniapp/src/components/LibraryDetailOverlay.vue`：存在 B 面时图区改为「左 A 右 B + 中间竖分隔线」并排布局；详情未返回前用摘要缩略图补位，返回后 B 面升级为高清 `displayImageUrl`。
5. **预览逻辑** `apps/miniapp/src/services/use-library-detail.ts`：`previewDetailArtwork(side)` 支持指定面打开大图预览，新增 `previewSide`；`apps/miniapp/src/components/BagImagePreview.vue` 新增 `startSide` prop，打开时定位到指定面。
6. **发现页主展位** `apps/miniapp/src/pages/showcase/index.vue`：有 B 面时正面图区变成双页 `swiper`（横滑切面 + 右侧竖排两圆点，实心红为当前面）；层级调整（`.flip-face--front` 提到 z7、`.hero-quick` 提到 z9），保证横滑手势与快捷按钮点击都能到达。

## 二、后台列表服务端排序

后台三类列表原先只在当前页内做客户端排序，改为「服务端全量口径排序 + 分页」，排序结果才是全量正确的。

### 改动

1. **提交列表** `apps/api/src/submissions/submissions-admin.controller.ts` / `service.ts`：新增 `sort`（`name` / `addedAt` / `byteSize`）与 `order`。`name` / `addedAt` 是主表列走数据库 `orderBy`；`byteSize` 是图片资产字节数聚合值，先全量取 id、聚合字节和后在内存排序分页，再只为当前页取完整行与签名 URL。
2. **用户列表** `apps/api/src/users/users-admin.controller.ts` / `service.ts`：新增 `sort`（`collectibleCount` / `shelfCount` / `storageUsedBytes` / `lastLoginAt`）与 `order`；计数类走关系 `_count`，容量与登录时间走主表列。
3. **审计日志** `apps/api/src/admin/admin.controller.ts` / `service.ts`：新增 `order`（按 `createdAt` 升降序）。
4. **后台界面** `apps/admin/src/App.tsx`：提交 / 用户 / 审计三个表格的列 `sorter` 由「客户端比较函数」改为服务端触发（`sorter: true` + `sortOrder`），表格 `onChange` 处理排序事件并回写 sort/order 状态、重置到第 1 页。
