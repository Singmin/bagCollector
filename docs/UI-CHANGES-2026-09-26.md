# UI 改动记录（2026-09-26）

本轮为「袋袋集」小程序的 UI 专项迭代：全部收藏页 1:1 对齐 H5 原型、首页/拍照页/设置页改版、底部导航栏重做，并新增离线 Mock 数据模式用于纯前端预览。

> 分支：`feature/ui-revamp`（基于 `main`）
> 涉及范围：仅 `apps/miniapp`、`apps/worker` 的展示层与构建脚本，不改业务接口协议。

---

## 一、离线 Mock 数据模式（新增）

**目的**：不启动后端（API/Worker/PostgreSQL/Redis）也能在微信开发者工具里看到完整 UI 与数据链路。

- 新增 `apps/miniapp/src/services/mock-data.ts`：内存假数据（4 个展示架 / 10 件收藏，按品牌分配真实袋子抠图 `static/figma/bags/`），覆盖列表、搜索、详情、统计等全部接口路径；查询串解析为手写实现（小程序运行时无 `URLSearchParams`）
- `services/http.ts`：构建时开关 `VITE_USE_MOCK`，Mock 模式下 `api()` / `login()` / `logout()` 全部走内存数据，不触网
- `env.d.ts`：补充 `VITE_USE_MOCK` 类型声明
- `package.json`（root + miniapp）：新增脚本 `build:miniapp:mock` / `build:mp-weixin:mock`
- 正式构建（`build:miniapp:local` 等）完全不受影响

## 二、全部收藏页（pages/library）

### 1. 交互对齐 H5 原型
- **横滑箭头**：`‹ ›` 文字换成 SVG 按钮（点击平滑滚动 80% 行宽），滚到两端对应箭头淡至 18% 且不可点
- **松手吸附**：横滑松手后对齐最近卡片槽（等价 H5 scroll-snap）
- **品牌候选下拉**：输入即弹出——命中子串红色加粗、右侧「已有 N 件」、靛蓝「＋ 新建品牌」；面板做流内展开（scroll-view 会裁掉绝对定位浮层）
- **标签候选下拉**：同上（`# 标签` + 件数 + 新建入口）
- **搜索无结果建议标签**：撤掉「清空搜索」按钮，改为最多 4 个「还能搜到」的出口标签（品牌/标签按件数排序），点按直接重搜；副文案改为「“xx”不在你的收藏里」
- **按压反馈**：切换钮 scale(.94)、箭头 scale(.86) 提亮、chips scale(.94)
- **视图切换过渡**：展架/宫格切换 0.26s 淡入上移
- **详情滚动底部渐隐**：55rpx 渐隐遮罩，滚到底自动收短

### 2. 视觉对齐 H5 原型
- 宫格卡面：冷调斜向渐变 + 1px 内白边，去掉黄色光斑与外描边
- 详情玻璃：新增噪点纹理层（`noise.png` 预烘焙，替代 H5 的 feTurbulence，4.5% 透明度）
- 展架标题与右侧「共 N 件」/箭头**底部对齐**，小字 12px
- 页面结构：顶部标题固定、搜索栏与内容随滚动（搜索栏不固定）
- **编辑表单改为底部半窗**（`.edit-sheet`）：0.38s 上滑、顶部拖拽指示条、白渐变卡面；表单 UI/交互不变（下划线纸感、候选下拉、保存校验），遮罩点击 = 取消；详情卡内固定 [编辑][完成]，半窗内固定 [取消][保存]
- 标签：输入上限 24→12 字、胶囊加 `#` 前缀、已有标签时隐藏占位文字
- 详情日期格式改短横线 `2026-09-13`（`services/format.ts` 的 `formattedDate` 增加分隔符参数）

## 三、首页（pages/showcase）

- 大卡片 `.flip-card` 尺寸改为 300×318（600×636rpx），并去除外投影（保留顶沿内高光）
- 空状态插图替换为用户提供的新图 `empty-state.png`
- Mock 藏品改用真实袋子抠图（6 张，按品牌对号分配）
- 「最近收集」区块：
  - 副行文案「最近收藏 · N 件」→「**最近15天 · N 件**」，字号 14px→**12px**（含「查看全部 →」）
  - 区块整体上移（margin-top −14rpx），标题与副行间距 0→16rpx
- 挂袋区提示「左右滑动 · 轻点在上方查看」字号 14px→**10px**

## 四、拍照页（package-editor/pages/add）

按设计稿 `Frame 92.png` 1:1 对齐（1 图px ≈ 1.5rpx）：
- 取景卡：左右边距 40rpx、圆角 60rpx、底色 `#e2c4ae`；高度改「弹性填充 + 上限 1130rpx」，小屏不溢出
- 虚线引导框：内嵌 56/200，560×732，描边 5rpx、圆角 36rpx（并按反馈下移）
- 快门：外圈 150rpx（红描边 4rpx + 白环 6rpx）、红芯 130rpx，严格水平居中
- 导航栏：标题「上传纸袋」与返回键**以右上角胶囊按钮实际位置垂直居中**——用 `getMenuButtonBoundingClientRect()` 推导导航行高（胶囊高 + 2×上下留白），任何机型同轴

## 五、设置页（package-settings/pages/settings）

- 改为「方案 A+B」半窗形态：上半截露出模糊场景图，冷调玻璃底座 + 纸感规则线从底部起（对齐原型 `.sheet`）
- 点半窗外任意空白 = 收起返回（先播放 340ms 下滑动画再 `navigateBack`），去掉原生返回按钮
- 新增组件 `components/settings-sheet/`

## 六、底部导航栏（custom-tab-bar）—— 多轮迭代最终形态

- **文案**：「陈列」→「首页」、「全部收藏」→「收藏架」
- **图标**：改用用户提供的底部专用 SVG（挂袋 / 三横杠），并做归一化：
  - 未激活 `#7A7C80`（与文字同色）、激活 `#C50405`
  - 有效描边统一 4.0rpx（横杠图标按图形归一化视框 24.34 / stroke 1.74）
  - 视觉宽度差控制在 3% 内
- **＋按钮**：红色胶囊 266×96rpx 全圆角 + 外圈（6rpx 底色缝 + 5rpx 红描边，双层 box-shadow），白色细「＋」
- **选中态**：红色文字，去掉了原型的底部圆点
- **布局**：条目 192×124rpx、bottom 12rpx、图标 56rpx、文字 24rpx/600；条目在「屏幕边缘 ↔ ＋胶囊」可用空间内居中（左右对称 ±0.5rpx）
- **关键修复**：胶囊由 `top` 改为 **`bottom` 锚定**（bottom 40 + 96/2 = 88rpx = 条目内容垂直中心）。原实现混用 top/bottom 锚点，而内容区高度 = 176rpx − 安全区是变量，导致全面屏机型上图标与胶囊错开约一个安全区高度
- 页面底部留白/护垫同步（176rpx 栏高口径）

## 七、搜索栏（全部收藏页）

- 与右侧切换钮**等高**（flex stretch，随按钮变化自动跟随）
- 圆角 29rpx、字号 24rpx、图标与切换钮统一规格（后按需求缩至 16px，并修复 SVG 视框裁切与居中）
- 材质与切换钮一致：白色半透明描边 + 半透明白底；按需求去掉了外投影（保留顶沿内高光）
- 字重与搜索框文字统一（400）
- 切换按钮的展架 icon：三条横杠加长（12→16）并中轴对齐；与宫格 icon 大小/颜色/粗细 1:1
