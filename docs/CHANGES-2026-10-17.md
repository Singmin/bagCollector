## 一、白描边（贴纸效果）功能

给透明抠图沿主体轮廓加一圈手绘感白描边（贴纸效果），用户链路与官方袋子链路统一支持；描边参数运营可调，并配套存量图回填脚本。

### 改动

1. **描边算法包** `packages/stroke`（新增）：`addWhiteStroke(source, params)` 实现手绘描边（alpha 膨胀 → `feDisplacementMap` 抖动 → 硬化/柔化）；`StrokeParams` 定义可调参数（粗细比例 / 波浪频率 / 起伏幅度 / 柔化 / 降采样），`DEFAULT_STROKE_PARAMS` / `strokeParamsSchema` 提供默认值与校验。
2. **后台描边预览页**（新增）：`apps/admin/src/StrokePreviewPage.tsx` + `apps/api/src/admin/stroke-preview.controller.ts` / `stroke-preview.service.ts`；后台菜单新增「描边预览」，实时预览并调节参数，保存后即写入 `AppSetting`（key=`stroke.settings`）。`apps/admin/src/App.tsx`、`apps/api/src/admin/admin.module.ts` 注册入口。
3. **用户链路接入** `apps/worker/src/processor.ts`：`writeRenditions()` 在抠图结果派生展示图/缩略图前，先 `trimTransparent` 再加描边（仅抠图结果，实拍裁剪图不加）；`getStrokeParams()` 读库并 30s 短缓存，`ratio=0` 时关闭描边。
4. **官方链路接入** `apps/worker/src/official-processor.ts`：`writeOfficialRenditions()` 同样按透明口径加描边（抠图结果 / 保留透明度的标准 PNG），与用户链路口径一致。
5. **配置** `apps/worker/src/config.ts`：描边参数由环境变量迁移到数据库配置，`DISPLAY_STROKE_RATIO` 已废弃（保留仅为兼容旧部署脚本）。
6. **存量回填脚本** `scripts/backfill-stroke.mjs`（新增）：遍历存量透明资产（用户 CUTOUT / 官方 CUTOUT / 官方透明 STANDARD），按 `trim → addWhiteStroke → resize` 重新派生并原地覆盖 DISPLAY/THUMBNAIL；默认 dry-run，`--execute` 才写；输出需要刷新的 CDN URL 清单。
7. **构建/依赖**：`package.json` 的 `build:backend` 增加 `@bagcollect/stroke build`；`apps/api`、`apps/worker` 的 `package.json` 新增 `@bagcollect/stroke` 依赖；`infra/Dockerfile` 运行时镜像复制 `packages/stroke`。
8. **预览脚本**（新增）：`scripts/preview-stroke.mjs` / `preview-stroke-photo.mjs` / `preview-stroke-ratios.mjs`，本地预览描边效果与参数调参。

### 部署注意

- worker 代码改动需重新构建部署镜像后生效（之后新图自动带描边）。
- 存量图需手动跑 `scripts/backfill-stroke.mjs` 回填，并手动刷新 CDN（脚本输出 URL 清单，见脚本头部注释）。
- 描边是否生效由后台「描边预览」页的 `ratio` 控制，`ratio=0` 即关闭。

## 二、小程序收藏日历页

首页新增日历入口，进入「收藏日历」页：把收藏记录按 `addedAt` 归组到月视图，有收藏的日期直接铺当天袋子缩略图，底部双卡（左「本月」统计、右「文件夹」今日收藏）。

### 改动

1. **日历页** `apps/miniapp/src/pages/calendar/index.vue`（新增）：月视图（周日首日），缩略图加载失败回退数字格；数据源 `GET /collectibles`，无后端改动。
2. **入口** `apps/miniapp/src/pages/showcase/index.vue`：首页右上搜索钮左侧新增日历入口按钮，任何状态（空数据/加载失败）都可见。
3. **路由与图标**：`apps/miniapp/src/pages.json` 注册 `pages/calendar/index`；新增图标 `apps/miniapp/src/static/figma/calendar.svg`。

### 部署注意

- 小程序端改动，重新编译 / 发布小程序即可，无后端改动。
