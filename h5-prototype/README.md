# BagCollect H5 交互原型

这是根据仓库 `README.md` 和 `PROJECT_STATUS.md` 制作的移动端高保真原型。

## 预览

直接打开 `index.html`，或在当前目录运行：

```bash
python3 -m http.server 4173
```

再访问 `http://127.0.0.1:4173`。

## 已覆盖的原型交互

- 陈列首页：最近上传、最近加入、按展示架横向浏览。
- 收藏详情：点击任意藏品打开详情。
- 全部收藏：按名称或标签搜索，按展示架筛选。
- 添加收藏：选择本地图片、填写名称/展示架/标签并加入当前会话。
- 设置摘要：展示收藏统计、本地存储和 iCloud 占位状态。

该原型只在浏览器当前会话中保存新增项目，不上传或长期存储用户图片。
